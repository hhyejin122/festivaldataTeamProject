# 팀 프로젝트
R Studio를 활용한 팀 프로젝트입니다.

## 프로젝트 소개
전국 공연행사 통계 데이터 분석 프로젝트입니다.

2014년부터 2026년까지의 전국 공연행사 데이터를 활용하여
연도·월별 행사 추이, 지역별 행사 분포, 입장연령, 객석 규모,
공연장 요금 등의 특성을 분석하고 시각화했습니다.

## 개발 환경
- R studio
- R
  
## 데이터 소개
- 데이터 출처: 공공데이터포털(data.go.kr)
- 데이터: 전국 공연행사정보 표준데이터(CSV)
- 데이터 기간: 2014년 ~ 2026년
- 분석 기간: 2019년 ~ 2026년

## 파일 구성
- `teamproject2codehanib.R` : 데이터 전처리 및 분석·시각화 코드
- `전국공연행사정보표준데이터.csv` : 분석에 사용한 원본 데이터
  
## 주요 분석
- 연도·월별 공연행사 수 추이 분석
- 지역별 행사 분포 분석
- 입장연령별 행사 분석
- 장소별 객석 수 TOP15 분석
- 공연장 규모별 유료요금 분석
- 행사내용 및 키워드 분석
- 위도·경도를 활용한 공연 분포 분석

## 시각화
- 선그래프
- 막대그래프
- 원형그래프
- 상자그림
- 트리맵
- 방사형 차트
- 워드클라우드
- 지도 시각화
